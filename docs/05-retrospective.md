# 05 · 复盘

## 实际用时（估计）

约 3 小时量级：语料与工具 → ReAct/决策器 → 验收用例与文档。未做 UI / 部署 / 多 Agent。

## 最难的问题

1. **既要「像 Agent」又要防假 ReAct**：不能用固定脚本打印假决策日志；Mock 必须读 observation 再分支，同时文档写清 Mock 边界。  
2. **冲突边界**：D01/D02 无优先级时，产品正确行为是「披露冲突 + 请求确认」，而不是「聪明地」合并成一个数。  
3. **追问消歧**：短问「那期限是多久？」依赖 history 拼出有效检索 query。

## 学习收获

- 企业知识问答的核心不是「答得流畅」，而是 **引用可追溯 + 冲突可解释 + 失败可感知**。  
- 步数/工具上限与 `incomplete` 状态是评审可观测的工程基本功。  
- 双路径（LLM + Mock）让无密钥环境下仍可复现验收。

## 未完成 / 下一步
